# Elenco dei file di TeX Live che finiscono in latex/texmf/.
#
# È l'insieme dei file che pdfTeX apre davvero per compilare il CV (rilevato
# osservando le richieste HTTP durante una compilazione), più un margine di
# sicurezza sui font: ogni .tfm ha il suo .pfb, così qualsiasi corpo o stile
# il documento decida di usare è comunque incorporabile nel PDF.
#
# Se una compilazione si ferma con "File ... not found" oppure "Font ... not
# loadable", aggiungi qui il percorso e rilancia:
#
#   python3 build_texmf.py --source "$(kpsewhich -var-value=TEXMFROOT)"
#
# I percorsi sono relativi alla radice del bundle (latex/texmf/).
